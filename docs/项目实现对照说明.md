# FlowSync 项目实现对照说明

基于当前仓库源码、数据库脚本和《FlowSync 需求规格说明书》整理。

## 已完成

### 1. 基础工程
- 前端：Vue 3 + Vue Router 4 + Element Plus + Axios。
- 后端：Spring Boot 3.3.5 + MyBatis-Plus + SpringDoc OpenAPI。
- 前后端代理、API 基址、统一响应封装都已接好。
- 数据库脚本 `demo/database/flowsync_simple.sql` 已提供，并带有初始测试数据。

### 2. 登录与认证
- 已实现登录接口 `/api/auth/login`。
- 前端已实现登录页、登录态缓存、退出登录。
- 路由已做登录态拦截。
- 请求拦截器会自动附加 `currentUserId`。

### 3. 工作台与统计
- 已实现总览页。
- 已展示成员数、项目数、任务数、总结数。

### 4. 项目管理
- 已实现项目列表、创建、编辑、删除。
- 已支持负责人、状态、优先级、时间范围。

### 5. 任务管理
- 已实现任务列表、创建、编辑、删除。
- 已支持按项目、状态、标题筛选。
- 已支持父子任务字段 `parentId`。
- 成员在前端只能更新自己负责任务的状态。
- 已接入单任务 AI 建议。

### 6. AI 拆解
- 已实现单任务建议接口 `/api/ai/task-suggestion`。
- 已实现任务拆解接口 `/api/ai/task-plan`。
- 已实现拆解结果导入接口 `/api/ai/task-plan/import`。
- 已做 AI 失败兜底方案。
- 已支持导入前调整负责人。

### 7. 进度跟踪
- 已实现进度记录列表和新增。
- 已支持按任务筛选。

### 8. 总结中心
- 已实现总结列表和新增。
- 已支持选择项目、任务、总结类型和内容。

### 9. 成员与个人信息
- 已实现成员列表。
- 已实现个人信息页。
- 已实现修改密码。

### 10. 文档与接口
- 已提供 Swagger/OpenAPI 配置。
- 已提供启动说明。

## 未做 / 尚未落地

### 1. 后端权限校验
- 当前主要靠前端菜单和按钮控制。
- 后端接口没有做严格的角色鉴权。

### 2. 密码安全
- 密码仍是明文存储和明文比对。

### 3. 认证机制
- 仍是简化方案，没有 JWT 或 Session。
- 主要通过 `currentUserId` 查询参数传递身份。

### 4. 级联删除
- 删除项目或任务时，没有同步清理子任务、进度、总结。

### 5. 分页查询
- 列表接口仍是全量返回，没有分页。

### 6. 数据隔离
- 当前用户仍可看到全量数据，没有按角色或归属做隔离。

### 7. 操作日志
- 还没有关键操作审计表和日志链路。

## 现阶段结论

这个项目已经把“登录 - 项目 - 任务 - 进度 - 总结 - 统计 - AI 拆解”主流程跑通了，属于可演示的教学版成品。

但它也明确保留了几项简化实现：权限校验、密码加密、JWT、分页、级联删除、数据隔离和操作审计都还没做，后续如果要往正式系统靠，需要优先补这些。
